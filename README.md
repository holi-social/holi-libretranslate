# holi-libretranslate

A Self-hosted translation service powered by [LibreTranslate](https://github.com/LibreTranslate/LibreTranslate).

## Getting Started

To run the service locally, execute the following command:

```bash
./mprocs-start.sh
```

The service will start running on port `5000`. You can access it at: [http://localhost:5000](http://localhost:5000)
